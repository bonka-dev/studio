# Generated Output Policy

Bonka does not claim ownership of a project author's input files or generated
project output.

Assets, data, configurations and code generated from a project author's inputs
are not placed under GPL-3.0-or-later solely because Bonka generated them. This
includes converted images, map, entity and animation data, JSON and binary
output, and generated headers containing only project-specific data such as
`constexpr` values.

This policy is a clarification of the boundary between Bonka and a project. It
does not grant an additional GPL permission or override the GPL.

It does not cover GPL implementation code copied from Bonka, GPL libraries
directly linked into a project, or the license of a project author's inputs.
Official generators must therefore emit project-specific data and adapters, not
copied GPL runtime implementations.
